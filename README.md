# Team Agnirath — Website Showcase

Official website for **Team Agnirath**, a student-led solar electric car racing team from the Centre for Innovation (CFI), IIT Madras.

This was my first project as a web developer, built using React, Bootstrap, and AOS (Animate on Scroll).

🔗 **Live Demo**: [https://sagardng.github.io/Agnirath-Showcase/](https://sagardng.github.io/Agnirath-Showcase/)

---

## 🚀 Tech Stack
- **Frontend**: React.js, React-Bootstrap, Bootstrap 5
- **Animations**: AOS (Animate On Scroll)
- **Icons**: React Icons
- **Deployment**: GitHub Pages (automated via GitHub Actions)

---

## 🔒 Privacy Notice
> To protect the privacy and personal data of previous teammates, personal contact information, roll numbers, external profile links, and individual photos have been anonymized with dummy placeholders.
